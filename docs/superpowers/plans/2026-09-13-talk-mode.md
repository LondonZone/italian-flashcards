# Talk Mode (First Build) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a 4th practice mode, "Talk," for spoken Italian conversation practice with real-time AI correction (record → transcribe → reply → speak), plus a 5th "Mistakes" tab aggregating correction categories, backed by two new Firebase Cloud Functions and per-user Firestore data.

**Architecture:** Two new Firebase Cloud Functions (`transcribeAudio` using OpenAI Whisper, `chatReply` using OpenAI GPT-4o-mini with structured JSON output) live in a new `functions/` Node project alongside the existing static `italian_flashcards.html`. The frontend gains a hardcoded scenario picker, a chat UI reusing the existing `speakItalian()` TTS pipeline and Firebase Auth/Firestore already wired into the page, and a Mistakes tab that aggregates a new `mistakes` subcollection.

**Tech Stack:** Firebase Cloud Functions v2 (Node, `onCall`), Firebase Admin/Client SDKs (already loaded via CDN compat scripts), OpenAI Node SDK (Whisper + GPT-4o-mini with `json_schema` structured output), vanilla JS (no bundler, matches existing single-file pattern), Node's built-in `node:test` for backend unit tests.

## Global Constraints

- No OpenAI/API keys in client-side JS — only via Firebase Functions secrets (`OPENAI_API_KEY`, set with `firebase functions:secrets:set`).
- The Firebase project must be on the Blaze plan for Cloud Functions to make outbound network calls — this is a manual one-time Firebase Console step, called out in Task 1.
- `transcribeAudio` and `chatReply` are both `onCall` functions that reject unauthenticated requests (`request.auth` must be present) — Talk mode is gated behind Firebase sign-in.
- Category taxonomy for corrections is exactly: `word_order`, `infinitive_vs_conjugated`, `gender_agreement`, `verb_conjugation`, `vocabulary`, `other`. Never invent new categories in code.
- `chatReply` looks up the scenario's `systemPromptAddition` **server-side** from a hardcoded array — never trust a `systemPromptAddition` sent from the client.
- No transcript/history data is ever considered optional to protect — Firestore writes only happen after both `transcribeAudio` and `chatReply` succeed for a turn (never partial writes).
- Follow the existing file's conventions: vanilla JS, `Space Mono`/`Fraunces` fonts, the existing CSS custom properties (`--paper`, `--ink`, `--navy`, `--ochre`, `--rust`, `--sage`, `--line`, `--card-back`), and the existing `mode-btn`/`ctrl-btn`/`filter-btn` class patterns.
- Do not touch Flashcards, Fill-in-Blank, or Learn mode code, and do not touch the pending "All Grammar vs Texting" filter work or the Learn-mode multiple-choice fix.
- Show a diff before committing anything; never push straight to `main` without the user reviewing.

```js
// functions/lib/transcribe.js
const { toFile } = require('openai/uploads');

async function transcribeAudioBuffer(openaiClient, audioBuffer, mimeType) {
  const extension = mimeType.includes('mp4') ? 'mp4' : 'webm';
  const file = await toFile(audioBuffer, `audio.${extension}`, { type: mimeType });

  const result = await openaiClient.audio.transcriptions.create({
    file,
    model: 'whisper-1',
    language: 'it'
  });

  const transcript = (result.text || '').trim();
  return { transcript, isEmpty: transcript.length === 0 };
}

module.exports = { transcribeAudioBuffer };
```

```js
// functions/lib/chat.js
const CATEGORIES = [
  'word_order',
  'infinitive_vs_conjugated',
  'gender_agreement',
  'verb_conjugation',
  'vocabulary',
  'other'
];

function buildSystemPrompt(scenario) {
  return [
    'You are an Italian conversation partner for an A1-level English-speaking learner named David.',
    `Stay in character for this scenario: ${scenario.systemPromptAddition}`,
    'Keep your Italian reply short (1-3 sentences) and at A1 vocabulary level.',
    'David has two recurring error patterns to watch for specifically:',
    '1. Importing English word order into Italian sentences.',
    '2. Using an infinitive verb where a conjugated verb is required.',
    "Review David's latest message for ANY mistakes (not just those two patterns) and return each one as a correction.",
    `Every correction must use a category from exactly this list: ${CATEGORIES.join(', ')}.`,
    'If there are no mistakes, return an empty corrections array.',
    'Respond only with the reply_italian and corrections fields — no extra commentary.'
  ].join('\n');
}

const RESPONSE_SCHEMA = {
  name: 'talk_reply',
  schema: {
    type: 'object',
    properties: {
      reply_italian: { type: 'string' },
      corrections: {
        type: 'array',
        items: {
          type: 'object',
          properties: {
            mistake: { type: 'string' },
            correction: { type: 'string' },
            explanation: { type: 'string' },
            category: { type: 'string', enum: CATEGORIES }
          },
          required: ['mistake', 'correction', 'explanation', 'category'],
          additionalProperties: false
        }
      }
    },
    required: ['reply_italian', 'corrections'],
    additionalProperties: false
  },
  strict: true
};

async function getChatReply(openaiClient, { history, transcript, scenario }) {
  const messages = [
    { role: 'system', content: buildSystemPrompt(scenario) },
    ...history.map((turn) => ({
      role: turn.role === 'user' ? 'user' : 'assistant',
      content: turn.text
    })),
    { role: 'user', content: transcript }
  ];

  const completion = await openaiClient.chat.completions.create({
    model: 'gpt-4o-mini',
    messages,
    response_format: { type: 'json_schema', json_schema: RESPONSE_SCHEMA }
  });

  const raw = completion.choices[0].message.content;
  return JSON.parse(raw);
}

module.exports = { CATEGORIES, buildSystemPrompt, getChatReply, RESPONSE_SCHEMA };
```

```js
// functions/index.js
const { onCall, HttpsError } = require('firebase-functions/v2/https');
const { defineSecret } = require('firebase-functions/params');
const OpenAI = require('openai');
const { getScenario } = require('./lib/scenarios');
const { transcribeAudioBuffer } = require('./lib/transcribe');
const { getChatReply } = require('./lib/chat');

const openaiApiKey = defineSecret('OPENAI_API_KEY');

async function handleTranscribeAudio(request, { makeOpenAIClient }) {
  if (!request.auth) {
    throw new HttpsError('unauthenticated', 'Sign in required.');
  }
  const { audioBase64, mimeType } = request.data || {};
  if (!audioBase64 || !mimeType) {
    throw new HttpsError('invalid-argument', 'audioBase64 and mimeType are required.');
  }
  const openaiClient = makeOpenAIClient();
  const buffer = Buffer.from(audioBase64, 'base64');
  return transcribeAudioBuffer(openaiClient, buffer, mimeType);
}

async function handleChatReply(request, { makeOpenAIClient }) {
  if (!request.auth) {
    throw new HttpsError('unauthenticated', 'Sign in required.');
  }
  const { history, transcript, topicId } = request.data || {};
  if (!transcript || !topicId) {
    throw new HttpsError('invalid-argument', 'transcript and topicId are required.');
  }
  let scenario;
  try {
    scenario = getScenario(topicId);
  } catch (err) {
    throw new HttpsError('invalid-argument', `Unknown topicId: ${topicId}`);
  }
  const openaiClient = makeOpenAIClient();
  return getChatReply(openaiClient, { history: history || [], transcript, scenario });
}

exports.transcribeAudio = onCall({ secrets: [openaiApiKey] }, (request) =>
  handleTranscribeAudio(request, {
    makeOpenAIClient: () => new OpenAI({ apiKey: openaiApiKey.value() })
  })
);

exports.chatReply = onCall({ secrets: [openaiApiKey] }, (request) =>
  handleChatReply(request, {
    makeOpenAIClient: () => new OpenAI({ apiKey: openaiApiKey.value() })
  })
);

// Exported for unit testing (Task 5's test/index.test.js).
exports.handleTranscribeAudio = handleTranscribeAudio;
exports.handleChatReply = handleChatReply;
```

```js
let talkMediaRecorder = null;
let talkRecordedChunks = [];
let talkRecording = false;

function talkPickMimeType(){
  const candidates = ['audio/mp4', 'audio/webm;codecs=opus', 'audio/webm'];
  for(const type of candidates){
    if(window.MediaRecorder && MediaRecorder.isTypeSupported(type)) return type;
  }
  return '';
}

async function talkToggleMic(){
  if(talkRecording){
    talkMediaRecorder.stop();
    return;
  }
  showTalkError('');
  let stream;
  try{
    stream = await navigator.mediaDevices.getUserMedia({ audio: true });
  }catch(err){
    showTalkError("Couldn't access the microphone — check permissions.");
    return;
  }
  const mimeType = talkPickMimeType();
  if(!mimeType){
    showTalkError("This browser can't record audio.");
    stream.getTracks().forEach(t => t.stop());
    return;
  }
  talkRecordedChunks = [];
  talkMediaRecorder = new MediaRecorder(stream, { mimeType });
  talkMediaRecorder.ondataavailable = (e) => { if(e.data.size > 0) talkRecordedChunks.push(e.data); };
  talkMediaRecorder.onstop = () => {
    stream.getTracks().forEach(t => t.stop());
    talkRecording = false;
    document.getElementById('talkMicBtn').classList.remove('recording');
    handleTalkRecordingStopped(mimeType);
  };
  talkMediaRecorder.start();
  talkRecording = true;
  document.getElementById('talkMicBtn').classList.add('recording');
}

function blobToBase64(blob){
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onloadend = () => resolve(reader.result.split(',')[1]);
    reader.onerror = reject;
    reader.readAsDataURL(blob);
  });
}

async function handleTalkRecordingStopped(mimeType){
  const blob = new Blob(talkRecordedChunks, { type: mimeType });
  const audioBase64 = await blobToBase64(blob);
  const micBtn = document.getElementById('talkMicBtn');
  micBtn.disabled = true;
  try{
    const transcribeFn = functionsClient.httpsCallable('transcribeAudio');
    const { data } = await transcribeFn({ audioBase64, mimeType });
    if(!data.transcript || data.isEmpty){
      showTalkError("Didn't catch that — try again.");
      return;
    }
    await handleTalkTranscript(data.transcript);
  }catch(err){
    console.error('transcribeAudio failed:', err);
    showTalkError("Couldn't transcribe that — try again.");
  }finally{
    micBtn.disabled = false;
  }
}
```

```js
/* ---------- MISTAKES MODE ---------- */
async function renderMistakes(){
  const wrap = document.getElementById('mistakesList');
  if(!hasFirebaseUser()){
    wrap.innerHTML = '<div class="empty">Sign in to see your mistake history.</div>';
    return;
  }
  wrap.innerHTML = '<div class="empty">Loading...</div>';
  try{
    const snapshot = await db.collection('users').doc(currentUser.uid).collection('mistakes').get();
    const counts = {};
    snapshot.forEach(doc => {
      const category = doc.data().category || 'other';
      counts[category] = (counts[category] || 0) + 1;
    });
    const sorted = Object.entries(counts).sort((a, b) => b[1] - a[1]);
    if(!sorted.length){
      wrap.innerHTML = '<div class="empty">No mistakes logged yet — go practice in Talk mode.</div>';
      return;
    }
    wrap.innerHTML = '';
    sorted.forEach(([category, count]) => {
      const row = document.createElement('div');
      row.className = 'mistake-row';
      const label = category.replace(/_/g, ' ');
      const times = count === 1 ? 'time' : 'times';
      row.innerHTML = `<span>${label}</span><span>${count} ${times}</span>`;
      wrap.appendChild(row);
    });
  }catch(err){
    console.error('Could not load mistakes:', err);
    wrap.innerHTML = '<div class="empty">Could not load mistake history.</div>';
  }
}
```
